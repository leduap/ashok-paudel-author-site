## Headings break a post into sections

A post is plain text with a few simple marks. A line that starts with `##` becomes a section heading like the one above. A blank line starts a new paragraph.

Text can be **bold** or *italic*, and a post can link to another page, for example [the blog index](../).

## Lists

A short list of the things a post can contain:

- paragraphs, headings and lists
- quotations
- simple tables
- links

Numbered lists work too:

1. Write the file.
2. Add it to the `posts` folder.
3. The site rebuilds itself.

## Quotations and tables

> A quotation is set apart from the rest of the text like this.

| Term | Plain meaning |
| --- | --- |
| Budget | The plan for the year |
| Forecast | The latest estimate of how the year will turn out |
| Variance | The difference between the two |

---

That is everything a post needs. Anything typed as HTML, such as <b>this</b>, is shown as plain text and is never run.
